# PDF Invoice to Excel Extractor 🧾➡️📊
### (نظام أتمتة واستخراج فواتير صيانة السيارات إلى إكسل)

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)
![Tesseract OCR](https://img.shields.io/badge/Tesseract-OCR-green)
![Pandas](https://img.shields.io/badge/Pandas-Data_Processing-orange)

أداة أتمتة متقدمة مبنية بلغة **Python** مخصصة لاستخراج البيانات المالية والتفصيلية من فواتير الـ PDF الممسوحة ضوئياً (باللغة العربية والإنجليزية) وتصديرها وتنظيمها تلقائياً بمرونة وسرعة في تقارير **Excel**، مع التركيز على دقة معالجة نصوص وتقسيمات الفواتير المعقدة.

---

## 🌟 الميزات (Features)

* **📖 التعرّف البصري على الحروف (OCR):** يستخدم محرك `Tesseract OCR` لقراءة نصوص الفواتير الممسوحة ضوئياً واستخراج البيانات العربية بدقة عالية.
* **💰 التوزيع الديناميكي لطرق الدفع:** يتعرف تلقائياً على قنوات الدفع (شبكة، كاش، تحويل، تابي) سواء كانت منفردة، ثنائية، أو مشتركة. ويقوم بتوزيع المبالغ بدقة لضمان أن مجموعها يطابق **الإجمالي النهائي للفاتورة**.
* **⚙️ معالجة الأجزاء الخارجية والمخارط (Parts & Services):**
  * استخراج فواتير "قطع غيار الوكالة" بحساب الإجمالي مع الضريبة (`البيان=الإجمالي مع الضريبة`).
  * استخراج "قطع غيار خارجية" بسعر الإفراد قبل الضريبة (`البيان=الأفرادي`).
  * استخراج تكاليف "المخرطة" تلقائياً وإدراجها مع وصف البيان (`البيان=المبلغ`).
* **👨‍🔧 تقسيم أجور العمالة (Labor Costs):** فصل أجور قسم "الكهرباء" و"الميكانيكا" بشكل آلي بعد خصم قيمة القطع وحساب المبلغ قبل ضريبة القيمة المضافة (15%).
* **🛠️ استخراج ذكي للبيانات الأساسية:** استخراج اسم العميل، رقم الفاتورة، نوع واسم السيارة بشكل متكيف مع التشوهات البصرية البسيطة.
* **🛡️ معالجة الأخطاء الذكية:** حفظ موازي (Backup) في حالة كان ملف الإكسل المستهدف مفتوحاً لمنع تعارض الأذونات والمشاكل.

## 🚀 متطلبات التشغيل (Prerequisites)

تحتاج إلى تثبيت المكونات التالية ليتم عمل البرنامج بنجاح:

1. **Python 3.8+**: تأكد من إضافة بايثون للـ `PATH`.
2. **Tesseract OCR**: 
   * يجب تثبيت [Tesseract OCR for Windows](https://github.com/UB-Mannheim/tesseract/wiki).
   * تأكد من تثبيت الحزمة الخاصة بـ **اللغة العربية (ara)**.
   * مسار التثبيت الافتراضي للسكربت: `C:\Program Files\Tesseract-OCR\tesseract.exe`.
3. **مكتبات البايثون (Dependencies)**:
   يمكن تثبيت الحزم المطلوبة من خلال موجه الأوامر:
   ```bash
   pip install pytesseract PyMuPDF PyMuPDFb openpyxl pandas xlwings regex Pillow
   ```

## 💻 طريقة الاستخدام (Usage)

1. **إعداد المجلدات:**
   يرجى التأكد من مسار إدخال ملفات الـ PDF (مثل المجلد المشترك أو الديسكتوب الخاص بالجهاز). 
   تأكد كذلك من المسار المخصص لملف الإكسل النهائي `Day_test.xlsx`.

2. **التشغيل:**
   بإمكانك تشغيل المعالجة بطريقتين:
   * **عبر موجه الأوامر (CMD):**
     ```bash
     python batch_process_invoices.py
     ```
   * **بنقرة واحدة:** قم بتشغيل الملف `run_invoices.bat` لتنفيذ الأداة مباشرة.

3. **المخرجات:**
   * سيقوم البرنامج بقراءة كافة فواتير `pdf` الجديدة.
   * سيتم تفريغ البيانات في السجل المطلوب داخل ملف الإكسل النهائي وتنسيقها.
   * في حال كان السجل مفتوحاً في الخلفية، سيقوم السكريبت بإنشاء ملف `Day_test_updated.xlsx` كإجراء وقائي.
